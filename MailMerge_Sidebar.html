Email Quota Guidance

This shows your remaining daily sending limit from Google.

  • Gmail accounts typically have 2,000/day.
  • Workspace accounts may have more.
  • Limits are shared across all your Add-ons.

Mail Merge Templates

Select a Gmail Draft to use as your template.

  • Create a draft in Gmail first.
  • Use {{Column Name}} in the subject or body to auto-fill data.
  • Case must match your sheet headers exactly.

Mail Merge Process

Follow these steps for a successful merge:

  • Pull Placeholders: Scans your draft for {{tags}} and creates the necessary columns in your sheet.
  • Run Mail Merge: Processes rows where the 'Action' column is set to 'SEND' or 'DRAFT'.

Getting Started

Follow these 3 steps to run your first merge:

  1. Gmail Draft: Create a draft with tags like {{First Name}}.
  2. Select & Sync: Choose the draft above and click Pull Placeholders.
  3. Execute: Fill the data, set Action to SEND, and click Run.

Core Columns Guide

  • Action: Set to SEND for immediate mailing or DRAFT to create Gmail drafts for review.
  • To: Primary recipient email address.
  • Thread ID or Subject: (Advanced) Paste a Gmail Thread ID to reply to a specific conversation.
  • Attachments: Comma-separated list of Google Drive File IDs or URLs.

Pro Tips

  • Case Sensitive: Tags like {{Name}} must match the column header exactly.
  • HTML Support: Any formatting (bold, links, images) in your Gmail draft is preserved.
  • Status: The tool updates the Status column automatically after each row.
